# homebrew-tap

Official Homebrew tap for [bricklayor](https://github.com/bricklayor) projects.

## Usage

```bash
brew install bricklayor/tap/<formula>
```

Or add the tap once:

```bash
brew tap bricklayor/tap
brew install <formula>
```

### Available Formulae

- **[agents-history](https://github.com/bricklayor/agents-history)**: Fuzzy-search terminal session history for Claude Code, Codex, Grok, and Antigravity.
  ```bash
  brew install bricklayor/tap/agents-history
  ```
